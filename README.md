# codex-library

Template library for the CODEX team (OBSIDIAN reads approved templates from here).

- `catalog.json` - short list of all APPROVED templates. OBSIDIAN only reads this file and `library/`.
- `library/<template-id>/` - approved templates (index.html, style.css, script.js, info.json).
- `candidates/<date>-<template-id>/` - templates waiting for Dejan's review.
- `kit/<version>/` - CODEX Polish Kit (shared animations, hover, shadows, palettes, fonts).

Written by n8n (CODEX workflows). Do not edit by hand unless you know what you are doing.
- `sections/<group>/<variant>/` - layout library (header, hero, about, menu, gallery, reviews, contact, footer). See sections/README.md.
